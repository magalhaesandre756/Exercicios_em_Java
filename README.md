# Exercícios em Java

Repositório de exercícios práticos de Java, feitos durante a disciplina 
de Engenharia de Software, com foco em conceitos de orientação a objetos.

## Conteúdo

- `engsof/` — exercícios sobre uso de pacotes em Java: como criar e 
  importar pacotes, e como implementar getters, setters e construtores.
- `heranca/` — exercícios sobre herança em POO: uso de superclasses e 
  subclasses.
- `exercicio_aula_calculadora.java` — exercício básico feito em aula: 
  programa que pede ao usuário 3 números e calcula a média entre eles.

## Tecnologias

Java

## Aprendizados

Organização de código em pacotes, encapsulamento (get/set), construtores, 
herança entre classes e lógica básica de entrada de dados.
